## 3. תיקון המנוע

קובץ: `red-build/src/engine/layout/legacy-imud-flow.js`.

בענף שבו H6 אינה מתאימה ליתרת הטור הימני, הקוד מסיר כותרות זנב באמצעות `rollbackTrailingHeadings()`, מפחית את `ti` ומעביר את `block.fill` לטור השמאלי. לפני התיקון, אותה איטרציה המשיכה עם המשתנה המקומי `tok` הישן. כך H5 שהוחזרה לא נקראה מחדש, ואילו H6 הנוכחית הוצבה שוב באיטרציה הבאה.

התיקון:

```js
const rolledBack = rollbackTrailingHeadings();
ti -= rolledBack;
block.fill = 1;
if (rolledBack > 0) continue fillPage;
```

כאשר הוחזרו כותרות, הלולאה מתחילה מחדש מהטוקן הראשון שהוחזר. הכותרות מוצבות מחדש לפי סדר המקור בטור השמאלי, ורק לאחר מכן מעובדת הכותרת הנוכחית.

**גבולות השינוי:**
- ענף המעבר לטור השמאלי בלבד שונה.
- ענף `pageClose` לא שונה: הוא מסיים את `fillPage` ומעביר את המשך הטוקנים לעמוד הבא.
- לא שונו parser, מדידה, DP, תקציב הערות, אלגוריתם איזון, Worker protocol או תבניות גיאומטריות.
